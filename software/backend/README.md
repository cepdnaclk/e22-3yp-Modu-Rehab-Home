# Rehabilitation backend

This directory is reserved for device-data ingestion, session management, and
interfaces used by the rehabilitation dashboard.

- `app/`: future backend application and service integration code.
- `tests/`: future backend unit and integration tests.

The backend will coordinate data processing, ML inference, AI assistant
requests, and future persistence. Frameworks, protocols, a database, and
deployment have not been selected or implemented. No dependencies are added.

Broader sensor and system tests remain in the repository-level `tests/` directory.
See [the planned software architecture](../../docs/design/software-architecture.md).
